📋 Overview

프로젝트 소개

ESP32 마이크로컨트롤러와 웹 브라우저를 WebSocket으로 실시간 연동하여 스마트 로봇을 원격 제어합니다. 사용자가 직접 주행한 경로를 시간 단위로 기록하고, 정방향 재생 또는 역순 복귀(Return Home) 기능으로 정밀하게 재현할 수 있는 웹 기반 임베디드 제어 시스템입니다. NeoPixel LED가 방향별로 다른 색상을 표시하며, 키보드(W/A/S/D) 및 화면 D-Pad 모두 지원합니다.

사용 기술 및 환경

Wi-Fi · 블루투스 내장 MCU. 로봇의 메인 두뇌. 240MHz 듀얼 코어.

Communication WebSocket

D-Pad UI, 키보드 제어, 경로 기록 시스템. 별도 프레임워크 없음.

듀얼 채널 H-Bridge 모터 드라이버. PWM으로 속도 제어.
💡

GPIO 27번, 2개 연결. 방향별로 색상 변경하여 상태 시각화.
📦
Libraries ArduinoJson · WebSockets
ArduinoJson: 경로 JSON 파싱. WebSocketsServer: 실시간 통신.

📡 WebSocket Protocol

통신 명세

명령어 동작 모터 A (좌) 모터 B (우) LED 색상
f 전진 (Forward) LOW → HIGH HIGH → LOW 🟢 Green (0,255,0)
b 후진 (Backward) HIGH → LOW LOW → HIGH 🔴 Red (255,0,0)
l 좌회전 (Left Turn) LOW → HIGH LOW → HIGH 🟡 Yellow (255,255,0)
r 우회전 (Right Turn) HIGH → LOW HIGH → LOW 🔵 Blue (0,0,255)
s 정지 (Stop) LOW LOW ⚪ White (255,255,255)
// 연결: WebSocket Port 81 ws = new WebSocket(`ws://192.168.0.50:81`); // 명령 전송 예시 ws.send("f"); // 전진 ws.send("s"); // 정지 // 경로 재생: HTTP POST /play_path (Port 80) // Body: { "path": [{"cmd":"f","duration":1.2}, ...] }
✨ Key Features

핵심 기능

  • 🚀
    실시간 WebSocket 통신 지연 없는 양방향 통신. 키보드(W/A/S/D) 또는 D-Pad 버튼 입력 즉시 ESP32로 단일 문자 명령 전송.
  • 🔴
    주행 경로 메모리 기록 기록 시작 버튼 클릭 시 명령어(cmd)와 구동 시간(duration)을 JS 배열에 실시간 누적 저장. mousedown/mouseup 이벤트 기반 정밀 타이밍.
  • 🚗
    정방향 길 따라가기 (Replay) 저장된 시퀀스를 async/await + setTimeout으로 순차 재생. 각 스텝 사이 200ms 정지 구간 포함.
  • 🏠
    역순 제자리 복귀 (Return Home) 기록 배열을 reverse() 후 f↔b, l↔r 반전 매핑 적용. 동일 시간으로 역경로 자동 주행.
  • 💡
    NeoPixel 방향 시각화 방향별 고유 색상으로 로봇 상태를 LED로 즉각 표시. Adafruit_NeoPixel 라이브러리 사용.
🚦 How to Use

사용 방법 — Step by Step

1
ESP32 전원 켜기 & Wi-Fi 연결 ESP32가 192.168.0.50 로 부팅됩니다. 같은 Wi-Fi(FirstClass2.4G)에 연결된 기기에서 접속하세요.
2
mediapipe.html 열기 & 연결 테스트 IP 입력란에 192.168.0.50 을 확인하고 "연결 테스트" 버튼을 클릭하세요. 성공 시 WebSocket이 연결됩니다.
3
로봇 수동 제어 "🔴 운전 기록 시작" 버튼 클릭 → D-Pad 또는 키보드(W/A/S/D)로 로봇 조종 → "⏹ 운전 기록 정지"로 완료.
4
경로 재생 또는 복귀 "🚗 길 따라가기"로 동일 경로 반복 주행, "🏠 제자리 복귀"로 역방향 자동 복귀. 기록은 🗑️ 버튼으로 삭제 가능.
